## 重现与边界

本地检查：`tests/test_orchestration_acceptance.py`、`tests/test_orchestration_history_canonical.py` 与既有 `tests/test_orchestration_domains.py` 合计 **45 passed**。另用子进程确认最终默认 synthetic CLI 为 `PASS/exit 0`，四域全部 verified，其中 Memory 保持 `WAITING_FOR_REVIEW`；`--live` 无环境密钥为 `BLOCKED/AUTH_REQUIRED/exit 2`，在创建临时业务数据与网络调用前停止。

默认执行 `python -m cognivault.orchestration.acceptance` 使用明确标注 synthetic 的回调和临时 Gateway，退出码 0 表示该隔离合成验收通过。`--live` 选择仅从环境读取密钥的 HTTPS 执行器；缺凭据在网络前返回 BLOCKED/AUTH_REQUIRED，退出码 2。`--executor harness --installation-root <trusted-installation> --credential-path <existing-provider-credential>` 显式选择安装版执行器，只由官方凭据服务消费已有认证文件，验收不读取、复制或打印认证内容。不接受私有 Gateway config 参数。

正式 Desktop MCP Host、安装包用户环境及跨 Host 证据未由本 SDK 验收覆盖；这些发布门禁仍需另行满足，本报告不授权发布。
