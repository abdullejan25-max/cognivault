- 编排任务、执行器描述、回执和结果校验；区分 CONFIGURED（已配置）、CONNECTED（连接成功）和 VERIFIED（针对指定任务验证成功）。
- 有限调用与重试、外传授权筛选、任务重放约束、Gateway 持久化和独立回读；日志只保留任务元数据。
- 受限 Harness/标准 HTTPS 执行器、可信依赖计划、canonical History 与三域验收入口；真实模型、自动故障测试、隔离 Gateway 和当前 Desktop MCP 分别记录，当前状态不构成完整发布验收通过。
- 候选版本一致性检查、动态版本包审计与锁文件中的直接 `httpx` 依赖。

## 安装与兼容

Python 要求仍为 `>=3.11`，发行包与 canonical import 为 `cognivault`。保留 `study-migrate = cognivault.migration.cli:main` 和 deprecated `chatgpt_study_system.transports.mcp_stdio` 启动 shim；不承诺其它旧 Python API 兼容。

已有 CogniVault 安装可以在隔离环境试装候选 wheel。仍使用旧发行包 `chatgpt-study-system-v2` 时，按 [README 升级步骤](../../README.md#upgrade-from-the-former-distribution) 先卸载旧发行包，再安装 CogniVault，避免共享 shim 和 launcher 被后续卸载移除。正式用户环境的替换、Host 重启和信任确认应保留为独立步骤。

升级不要求数据库迁移、重新导入或更改个人数据路径和权限。任何真实 Study/History/Sources/Wrong Answers/Assets 读取和写入都经过已注册 Gateway；历史 `study_system` provenance 和命名的隔离服务器保持原含义。
